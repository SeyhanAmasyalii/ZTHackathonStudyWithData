# Copilot istemleri (kopyala-yapıştır)

Kaynak ve açıklamalar: `docs/COPILOT-MERCEK-PROMPTLARI.md`.

1. `00-sistem-talimati.md` içeriğini hackathon reposunda `.github/copilot-instructions.md` dosyasına koyun
   (dosya varsa CodeQL/güvenlik kurallarını silmeden altına ekleyin).
2. Repoya kopyalayın: `datav2/`, `prompts/mercek-chat.md`, `docs/`.
3. VS Code → Copilot Chat → **Agent** modu. Her `faz-NN-*.txt` dosyasının içeriğini **yeni bir sohbette** sırayla yapıştırın.
4. Her fazdan sonra kontroller yeşil ve kabul kriteri sağlanınca commit; sonra sonraki faz.
